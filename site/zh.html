How it works

会话活在服务器上，
手机只是那块屏幕

收起手机，任务照跑

09:12 在地铁口派出一个重构任务，然后把手机装回兜里。进隧道、切出去回微信、锁屏——服务器上的活一秒没停。

  • 会话真身是服务端 tmux，手机断开只是「屏幕拔了」
  • 按序号记账，重连只补你错过的那一段，不重发
  • 长输出无上限滚动，输入行始终钉在底部

Features

一个二进制，装完就齐

前端内嵌、同端口服务。下载、运行、配对——没有第四步。

▣

多会话终端

机器上所有 tmux 会话都在列表里，包括不是它开的。三态灯 + 末行预览，一眼看出哪个在跑、哪个卡着等你。

⌨

自定义全键盘

手机敲终端不再是酷刑。键位三选一 —— 完整笔记本布局，或者更大的键、符号一滑就出 —— 外加智能命令联想、快捷指令多设备同步。

🗀

文件与 Git

不用退回终端敲 cat。目录树、代码编辑、Markdown 与图片预览、工作区 diff、上传下载。

🔔

完成即推送

Claude Code / Codex / opencode / Kimi CLI 的完成钩子自动接线，按工具独立开关，不用你写配置。

🔒

端到端加密

每次连接一次完整 Noise IK 握手。中间的隧道和反代只经手密文，看不见你的终端。

◎

加到主屏就是 App

七套主题外加自行导入的 Ghostty 配色、五套等宽字体、中英双语、应用内一键更新、AI 上下文用量实时可见。

PocketShell 不替代 SSH——它假设你已经有 tmux 和一台常开的机器，只是把「人不在场那段」补上。

三分钟，跑起来

宿主机只要有 tmux 和 git。Linux / macOS 都行。不用域名、不用配反代 —— 一条命令就能拿到真 HTTPS 地址。

1

一行安装

自动认平台、校验 SHA256，装完直接把下一条命令连路径一起打出来。

2

注册成服务

开机自启，第一次安装会直接把配对串打出来。

3

拿一个公网地址

没有域名？tunnel setup 走 Tailscale Funnel 给你一个 —— 除两次浏览器授权外全自动。已有域名就跳过这步。

4

手机配对

浏览器打开、粘贴、加到主屏幕，完事。

terminal
# 安装 —— 它会把下一条命令连正确路径一起打出来
$ curl -fsSL https://raw.githubusercontent.com/Big-Pony/pocketshell/main/install.sh | sh

# 没有域名：先填占位地址，下一步会自动替换
$ sudo pocketshell-agent install \
    --advertise ws://127.0.0.1:8722 --name my-server
$ sudo pocketshell-agent tunnel setup

# 已有域名？只要这一条（macOS 无需 sudo）
$ pocketshell-agent install \
    --advertise wss://your.domain --name my-mac
Security

你的机器，你的密钥

所有安全性压在「谁能配对」这一个点上——所以这个点被层层把守。

Noise IK 握手

双向认证 + 前向保密。没登记过的设备，握手这关就过不去。

一次性配对码

300 秒过期、限次、限速。爆破会被锁。

吊销即刻生效

命令行一句话踢掉一台设备，在线连接几秒内断开，推送订阅一并清除。

全程留痕

握手、配对、吊销、锁定都结构化落盘，随时可查——但不记录你的命令和终端内容。
